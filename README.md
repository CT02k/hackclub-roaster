# Hackclub Roaster

Roast yourself with your hackclub data with the power of AI

![screenshot](https://171.digital/q3I815rtaWHJiKte)

## Try it
https://hackclub-roaster.vercel.app

## Running locally
```bash
git clone https://github.com/ct02k/hackclub-roaster
cd hackclub-roaster
cp .env.example .env
npm install
npm run dev
```

## Built with Next.js, TailwindCSS, and TypeScript
